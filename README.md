# 五線譜 → 縦譜 変換ツール

和楽器（箏・十七絃）のポピュラーな記譜法である縦譜（枠型）に、五線譜の音符を変換するための Web ツールです。ブラウザだけで動作し、外部依存はありません。

## 起動方法

```sh
python3 -m http.server 8000
# → http://localhost:8000/ をブラウザで開く
```

または `index.html` を直接ブラウザで開いてください。

## 現状の実装範囲（MVP）

- データモデル: 小節 → 拍 → 半拍セル
- 楽器切替: 箏（13絃）／十七絃
- 調弦表の編集（モーダル）／変換 (`pitch → 絃番号`)
- 変換できないとき: 半音下 → 左に「ヲ」、全音下 → 左に「オ」、それ以外は未変換セル表示
- テキスト入力:
  - `haf` / `lbss` / `mcn` （高/中/低 prefix、シャープ s, フラット f, ナチュラル n）
  - 和音: `c,e,g` のようにコンマ区切り
  - `1` 四分休符（1拍送り）, `2` 八分休符, `3`/`4` 伸ばし, `w` ヲ単独, `o` オ単独
- セルの最小単位は16分音符（1/4拍）
- セルクリックでカーソル移動、**Enter=半拍送り**、空エンターで空白送り
- **Space=16分送り**（入力ありはそのセルに記入／未入力は△＋黒丸を置いて送る）
- **連符**（3/5/7連符・拍数指定）: 対象セルにスラー状の曲線＋数字を表示
- 五線譜サンプル（SVG）: ト音／ヘ音、♭による調号、クリックで A-G を入力欄に追加
- 拍子の変更（カーソル位置以降の小節に適用）
- 二重線による小節区切り（CSSで縁取り）
- localStorage 保存／読込

## ファイル構成

- `index.html` — UI 骨格
- `styles.css` — レイアウト・縦書き
- `js/state.js` — 状態管理／データモデル／既定調弦
- `js/tuning.js` — pitch→絃 変換（ヲ／オ フォールバック）
- `js/parser.js` — テキスト入力パース
- `js/render.js` — 縦譜グリッド描画
- `js/staff.js` — 五線譜 SVG とクリック入力
- `js/app.js` — イベント結線
