# イタリア6泊8日旅行プラン（2026年・関西発着 / ローマin・ベネツィアout）

> 他のバージョン: [3泊版](./italy-trip-plan-2026.md) / [4泊版（フィレンツェ1泊）](./italy-trip-plan-2026-4nights.md)。航空便・料金調査の前提は共通です（調査日: 2026年7月2日）。

- **旅行可能期間**: 2026年8月24日（月）〜9月15日（火）
- **滞在**: 現地6泊 — **ローマ2泊＋フィレンツェ2泊＋ベネツィア2泊のゴールデンルート**
- **発着**: 関西国際空港（KIX）発着
- **ルート**: オープンジョー — 往路ローマ（FCO）着 / 復路ベネツィア（VCE）発

## 1. 基準日程（このプランの前提）

全オプション共通で「**ローマ泊 9/7(月)・9/8(火)、フィレンツェ泊 9/9(水)・9/10(木)、ベネツィア泊 9/11(金)・9/12(土)、ベネツィア発 9/13(日)、関空帰着 9/14(月)**」に統一。

- **朝〜昼発の航空会社**（ルフトハンザ・エールフランス・KLM・中国東方）→ **9/7(月) 朝〜昼 関空発・同日夜ローマ着**。これが**ちょうど6泊8日**（9/7発→9/14帰着）。
- **夜発の航空会社**（ターキッシュ・カタール・エミレーツ・フィンエアー）→ **9/6(日) 夜 関空発**、9/7(月) 朝ローマ着。往復とも機中泊が入るため正確には**6泊9日**（9/6発→9/14帰着）になるが、その分ローマ初日が半日多く使える。
- 帰着9/14(月)は期間上限9/15に収まり、カタールのベネツィア夏季便（〜9/15）にも間に合う。
- 曜日制約の確認済み: カタール関空線（月火木金日）は往路9/6(日)✓・復路ドーハ発9/14(月)✓、QR126ベネツィア発（日月金土運航）は9/13(日)✓。
- **8月に行く場合**: 朝発組 8/24(月)発〜8/31(月)帰着（6泊8日）／夜発組 8/24(月)夜発〜9/1(火)帰着（6泊9日）。カタールの曜日制約もこのパターンで全て運航日（8/24月✓・VCE発8/31月✓・ドーハ発9/1火✓）。ただし夏休み料金で+2〜5万円。

## 7. 注意事項（6泊版固有）

1. 夜発組（TK/QR/EK/AY）は機中2泊のため**トータル9日間**（9/6発〜9/14帰着）。「8日間ちょうど」に収めたい場合は朝発組（LH/AF/KL/MU）を選ぶ（9/7発〜9/14帰着）。
2. カタール航空利用時、ドーハ⇔ベネツィア夏季便は9/15まで。9/13発が実質最終ウィンドウなので、ダイヤ変更に備え予約後も運航確認を。
3. ウフィツィ美術館・コロッセオ・バチカンに加え、**最後の晩餐級の人気枠は1〜2か月前に売り切れる**ことがある。行程確定後すぐ予約を。
4. ベネツィア2連泊はホテル代が高め（本島内）。予算を抑えるならメストレ地区泊（本島まで鉄道10分）も検討。
5. 3都市周遊は荷物移動2回。フィレンツェ・ベネツィアの石畳とヴァポレットを考えると、スーツケースは中型までが無難。
6. そのほかの注意（別切りリスク・推定料金・入島税など）は[3泊版セクション7](./italy-trip-plan-2026.md#7-注意事項)と共通。
