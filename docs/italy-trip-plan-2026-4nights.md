# イタリア4泊旅行プラン（2026年・関西発着 / ローマin・ベネツィアout）

> 他のバージョン: [3泊版](./italy-trip-plan-2026.md) / [6泊8日版（3都市周遊）](./italy-trip-plan-2026-6nights.md)。航空便・料金調査の前提は3泊版と共通です（調査日: 2026年7月2日）。

- **旅行可能期間**: 2026年8月24日（月）〜9月15日（火）
- **滞在**: イタリア4泊（機中泊を含め6〜7日間）— **フィレンツェを加えた3都市周遊が可能に**
- **発着**: 関西国際空港（KIX）発着
- **ルート**: オープンジョー — 往路ローマ（FCO）着 / 復路ベネツィア（VCE）発

---

## 1. 基準日程（このプランの前提）

全オプション共通で「**ローマ泊 9/9(水)・9/10(木)、フィレンツェ泊 9/11(金)、ベネツィア泊 9/12(土)、ベネツィア発 9/13(日)**」に統一。

- **夜発の航空会社**（ターキッシュ・カタール・エミレーツ・フィンエアー）→ **9/8(火) 夜 関空発**、9/9(水) ローマ着、**9/14(月) 関空帰着**
- **朝〜昼発の航空会社**（ルフトハンザ・エールフランス・KLM・中国東方）→ **9/9(水) 朝〜昼 関空発**、同日夜ローマ着、9/14(月) 関空帰着
- 帰着9/14(月)は期間上限9/15に収まり、**カタールのベネツィア夏季便（〜9/15）にも間に合う**。
- 曜日制約の確認済み: カタール関空線（月火木金日）は往路9/8(火)✓・復路ドーハ発9/14(月)✓、QR126ベネツィア発（日月金土運航）は9/13(日)✓。
- 8月に行く場合は **8/25(火)発〜8/31(月)帰着** が同じ曜日パターンでそのまま使えます（+2〜5万円）。

## 7. 注意事項（4泊版固有）

1. 帰着が9/14(月)になるため、**月曜に休みを取れるか**が3泊版との実質的な分かれ目（エールフランスなら月曜朝8:50着で午後から活動可能）。
2. カタール航空利用時、ドーハ⇔ベネツィア夏季便は9/15まで。**4泊版の9/13発が実質最終ウィンドウ**なので、ダイヤ変更に備え予約後も運航確認を。
3. フィレンツェのウフィツィ美術館は日時指定の事前予約がほぼ必須。ドゥオーモのクーポラ登頂も要予約。
4. 3都市周遊は荷物移動が2回増える。大きなスーツケースなら「ゆったり2都市案」（ベネツィア2連泊）も検討を。
5. そのほかの注意（別切りリスク・推定料金・入島税など）は[3泊版セクション7](./italy-trip-plan-2026.md#7-注意事項)と共通。
